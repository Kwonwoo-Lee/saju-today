# 사주 오늘

이름(영문), 생년월일, 태어난 시각(선택), 지역, 성별을 입력하면 정확한 만세력 계산으로
사주팔자(년주·월주·일주·시주)와 오늘의 운세를 보여주는 정적 웹사이트입니다.

## 계산 방식

- 절기 기준 년주/월주/일주/시주 계산은 [`lunar-javascript`](https://github.com/6tail/lunar-javascript)(6tail, MIT)에 위임합니다.
- 태어난 시각과 지역이 주어지면 **진태양시(眞太陽時) 보정**(경도차 + 균시차)을 적용해 시주 정확도를 높입니다.
- 오행(五行) 판정, 십성(十神) 판정, 오늘의 운세 해석은 `saju-engine.js`에서 직접 구현합니다.
- 태어난 시각을 모르면 시주(時柱)를 제외한 년주·월주·일주 3기둥만 표기합니다.
- 성별은 대운(大運)의 순행/역행 방향 계산에 사용됩니다.

빌드 도구 없이 순수 HTML/CSS/JS로 동작합니다.

## 다국어 페이지 (en/zh/fr/ko)

`index.html`(영어)과 `i18n.js`가 유일한 원본입니다. `/zh/index.html`, `/fr/index.html`,
`/ko/index.html`은 검색엔진이 언어별로 따로 색인할 수 있도록 **미리 렌더링해서 커밋해둔
정적 파일**이며, 직접 손으로 고치면 안 됩니다.

```bash
npm run build:lang   # index.html + i18n.js -> zh/fr/ko/index.html 재생성
```

`index.html`의 구조(새 섹션 추가 등)나 `i18n.js`의 번역 문구를 고쳤다면, 커밋 전에
반드시 이 명령을 다시 실행해서 4개 언어를 동기화하세요. (`scripts/generate-lang-pages.js`가
어떤 요소가 어떤 문자열에 대응하는지 매핑을 관리합니다 - `id`를 못 찾으면 스크립트가
에러로 즉시 알려줍니다.)

## 로컬 실행

```bash
npx serve .
```

## 로직 스모크 테스트

```bash
npm test
```

`lunar-javascript`의 공식 테스트 벡터와 결과를 대조하고, 십성 판정표가 고전 명리학 이론과
일치하는지 확인합니다.
